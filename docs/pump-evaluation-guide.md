# ポンプ滴下モード実機評価

## 対象ファームウェア

評価用firmware 0.3.17では自動散水を無効化している。ポンプはHome Assistantの個体差評価31〜36%を明示的に実行した場合だけ作動する。

## 安全準備

1. 吐出口を計量容器へ固定する。
2. 漏水しても問題のない場所で実施する。
3. Atom本体ボタンの緊急停止と「ポンプ評価を緊急中止」をすぐ操作できる状態にする。
4. 最初に手動でチューブを満水状態にし、各試験で同じ揚程とチューブ長を使用する。
5. ポンプや駆動回路に異音、停止、発熱があれば直ちに中止する。

## Home Assistantでの操作

31%から順に1条件だけを押す。GPIO2には20kHzのハードウェアPWMを30秒間連続出力する。吐水したDutyで一度評価を止め、そのDutyと1%下の条件を追加測定する。

| 条件 | PWM周波数 | Duty | 実行時間 |
|---|---:|---:|---:|
| 個体差評価31% | 20kHz | 31% | 30秒 |
| 個体差評価32% | 20kHz | 32% | 30秒 |
| 個体差評価33% | 20kHz | 33% | 30秒 |
| 個体差評価34% | 20kHz | 34% | 30秒 |
| 個体差評価35% | 20kHz | 35% | 30秒 |
| 個体差評価36% | 20kHz | 36% | 30秒 |

「ポンプ評価状態」が完了になるまで次の条件を開始しない。各端末について吐水した最小Dutyと水量を`pump-evaluation-results.csv`へ記録する。水は1.0gを約1.0mlとして換算する。端末間でチューブ長、揚程、満水状態、電源を揃える。

## 採用条件

- 10秒間、失速せず安定して吐水する。
- 3回の散水量の変動係数が10%以下である。
- 連続噴射ではなく、目的とする滴下状態になる。
- 異音、失速、過熱がない。
- 条件を満たす中で最小のDutyを採用する。

吐水状態は `滴下`、`細い連続水流`、`通常噴射`、`吐水なし` のいずれかで記録する。チューブが空の条件は別試験とし、通常の流量校正値へ混在させない。
