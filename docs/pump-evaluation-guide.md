# 固定Dutyによる時間散水

Firmware 0.3.26では個体別のポンプ校正を行わず、ポンプを20kHz・Duty 50%で駆動する。校正済み水分センサを前提に、自動散水は1回の短い散水後に長時間の保持確認を行う。

## 方針

- 確実な散水を優先し、滴下状態は必須要件にしない。
- キッティング時の個体別Duty校正は行わない。
- 通常散水はDuty 50%で最大10秒を1回だけ実行し、30分間ポンプを止めて水分保持を確認する。
- 散水中は1秒ごとに水分値を測定し、設定閾値以上になれば10秒未満でも直ちにポンプを停止する。
- 30分後も水分値が閾値未満なら再散水せず、`MOISTURE_NOT_RETAINED`でロックする。
- 手動散水テストもDuty 50%に固定し、3秒・5秒・10秒だけ選択できる。
- Firmware 0.3.26では自動散水を有効にする。水分センサ校正済みの端末だけへ配布する。

## 自動散水アルゴリズム

1. 水分値が設定閾値を下回ると散水サイクルを開始する。
2. 20kHz・Duty 50%で最大10秒散水する。散水中は1秒ごとに水分値を確認し、設定閾値以上なら即時停止する。
3. ポンプを停止し、30分間は再散水せずに水分保持を監視する。
4. 30分後の水分値が設定閾値以上ならサイクルを終了する。
5. 設定閾値未満なら `MOISTURE_NOT_RETAINED` でロックし、再散水しない。

ロック後はポンプを再始動せず、ロック状態をNVSへ保存して再起動後も維持する。土壌密度、水みち、センサと土の密着、吐出口位置を人が確認した後、Home Assistantの「散水ロックを確認して解除」を押した場合だけ解除する。ロック中もOTAと水分センサ校正は実行できる。

MQTTのdevice stateには `controllerState`、`wateringPulse`、`wateringLockout`、`wateringFaultCode` を含める。Home Assistantには `Watering Control Status` センサとして表示する。

## 安全確認

1. 吐出口を固定し、漏水しても問題のない場所で実施する。
2. Atom長押しの緊急停止をすぐ操作できる状態にする。
3. 異音、失速、発熱、吐水停止があれば直ちに中止する。
4. 端末によって50% Dutyでも吐水できない場合は、その個体を異常・非適合として扱い、Dutyの手動校正では吸収しない。

## 評価条件

| 操作 | PWM周波数 | Duty | 実行時間 |
|---|---:|---:|---:|
| 固定50%散水・3秒 | 20kHz | 50% | 3秒 |
| 固定50%散水・5秒 | 20kHz | 50% | 5秒 |
| 固定50%散水・10秒 | 20kHz | 50% | 10秒 |

評価では、吐水の有無、散水量、異音、失速、ポンプおよび駆動回路の発熱を確認する。
