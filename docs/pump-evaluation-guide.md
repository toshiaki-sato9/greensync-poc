# ポンプ滴下モード実機評価

## 対象ファームウェア

評価用firmware 0.3.19では自動散水を無効化している。40%では吐水せず50%で吐水した個体について、Home Assistantから41〜49%の始動境界を5秒間ずつ確認する。

## 安全準備

1. 吐出口を計量容器へ固定する。
2. 漏水しても問題のない場所で実施する。
3. Atom本体ボタンの緊急停止と「ポンプ評価を緊急中止」をすぐ操作できる状態にする。
4. 最初に手動でチューブを満水状態にし、各試験で同じ揚程とチューブ長を使用する。
5. ポンプや駆動回路に異音、停止、発熱があれば直ちに中止する。

## Home Assistantでの操作

41%から順に1条件だけを押す。GPIO2には20kHzのハードウェアPWMを5秒間出力する。各条件でモーター音・振動・吐水有無を確認し、`COMPLETED`後に次へ進む。初めて吐水したDutyで上位Dutyへの試験を止める。

| 条件 | PWM周波数 | Duty | 実行時間 |
|---|---:|---:|---:|
| 始動境界評価41% | 20kHz | 41% | 5秒 |
| 始動境界評価42% | 20kHz | 42% | 5秒 |
| 始動境界評価43% | 20kHz | 43% | 5秒 |
| 始動境界評価44% | 20kHz | 44% | 5秒 |
| 始動境界評価45% | 20kHz | 45% | 5秒 |
| 始動境界評価46% | 20kHz | 46% | 5秒 |
| 始動境界評価47% | 20kHz | 47% | 5秒 |
| 始動境界評価48% | 20kHz | 48% | 5秒 |
| 始動境界評価49% | 20kHz | 49% | 5秒 |

初めて吐水したDutyと1%下をそれぞれ合計3回試験する。3回すべて吐水する最小Dutyを最低安定Dutyとする。実運用Dutyは電源・温度変動を考慮し、最低安定Dutyへ2〜3%の余裕を加える。

## 採用条件

- 10秒間、失速せず安定して吐水する。
- 3回の散水量の変動係数が10%以下である。
- 連続噴射ではなく、目的とする滴下状態になる。
- 異音、失速、過熱がない。
- 条件を満たす中で最小のDutyを採用する。

吐水状態は `滴下`、`細い連続水流`、`通常噴射`、`吐水なし` のいずれかで記録する。チューブが空の条件は別試験とし、通常の流量校正値へ混在させない。
