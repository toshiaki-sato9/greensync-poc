# ポンプ滴下モード実機評価

## 対象ファームウェア

評価用firmware 0.3.15では自動散水を無効化している。ポンプはHome AssistantのPWM境界評価31〜34%を明示的に実行した場合だけ作動する。

## 安全準備

1. 吐出口を計量容器へ固定する。
2. 漏水しても問題のない場所で実施する。
3. Atom本体ボタンの緊急停止と「ポンプ評価を緊急中止」をすぐ操作できる状態にする。
4. 最初に手動でチューブを満水状態にし、各試験で同じ揚程とチューブ長を使用する。
5. ポンプや駆動回路に異音、停止、発熱があれば直ちに中止する。

## Home Assistantでの操作

次のうち1条件だけを押す。GPIO2には可聴域を避けた20kHzのハードウェアPWMを30秒間連続出力する。

| 条件 | PWM周波数 | Duty | 実行時間 |
|---|---:|---:|---:|
| PWM 31% | 20kHz | 31% | 30秒 |
| PWM 32% | 20kHz | 32% | 30秒 |
| PWM 33% | 20kHz | 33% | 30秒 |
| PWM 34% | 20kHz | 34% | 30秒 |

「ポンプ評価状態」が完了になるまで次の条件を開始しない。まず各条件を1回ずつ実施し、吐水境界を確認する。吐水した最小Dutyとその前後だけを3回測定し、増加重量を`pump-evaluation-results.csv`へ記録する。水は1.0gを約1.0mlとして換算する。

## 採用条件

- 10秒間、失速せず安定して吐水する。
- 3回の散水量の変動係数が10%以下である。
- 連続噴射ではなく、目的とする滴下状態になる。
- 異音、失速、過熱がない。
- 条件を満たす中で最小のDutyを採用する。

吐水状態は `滴下`、`細い連続水流`、`通常噴射`、`吐水なし` のいずれかで記録する。チューブが空の条件は別試験とし、通常の流量校正値へ混在させない。
