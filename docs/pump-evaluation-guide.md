# Home Assistantからの端末別ポンプ校正

Firmware 0.3.21以降は、端末ごとのPWM Dutyと実測流量をNVSへ保存できる。未校正端末および校正作業中は自動散水を禁止する。

## 安全準備

1. 吐出口を計量容器へ固定する。
2. 漏水しても問題のない場所で実施する。
3. Atom長押し緊急停止と「ポンプ校正を中止」を操作できる状態にする。
4. チューブを満水にし、実運用と同じ揚程・チューブ長・電源を使用する。
5. 異音、失速、発熱があれば直ちに中止する。

## 操作手順

1. Home Assistantで「① ポンプ校正を開始」を押す。
2. 「校正Duty（%）」へ、安定して吐水するDutyを入力する。
3. 「校正テスト時間（秒）」へ1〜60秒を入力する。
4. 「② 設定値でテスト散水」を押す。
5. 「ポンプ校正手順・結果」が実測待ちになるまで待つ。
6. 散水重量を測り、`1g ≒ 1ml`として「③ 実測水量（ml）」へ入力する。
7. 「④ 実測値から校正を保存」を押す。
8. 状態が成功になり、詳細属性の `calibrated` が `true`、`flowMilliMlPerSecond` が0より大きいことを確認する。

保存流量は次式で求める。

```text
flowMilliMlPerSecond = 実測水量[ml] × 1000 / 評価時間[秒]
```

## 保存範囲

- Duty: 1〜100%
- 評価時間: 1〜60秒
- 実測水量: 1〜1000ml
- 算出流量: 0.010〜50.000ml/秒

校正値は単一のNVSレコードとして保存する。入力不正または保存失敗時は以前の有効な校正値を維持する。OTA更新後も保存値を維持する。
