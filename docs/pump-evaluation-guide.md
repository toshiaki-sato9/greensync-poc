# 固定Dutyによる時間散水

Firmware 0.3.22では個体別のポンプ校正を行わず、ポンプを20kHz・Duty 50%で駆動する。自動散水は短いパルス散水と浸透待ちを繰り返して水分値を確認する。

## 方針

- 確実な散水を優先し、滴下状態は必須要件にしない。
- キッティング時の個体別Duty校正は行わない。
- 通常散水はDuty 50%で30秒散水し、3分間ポンプを止めて土壌への浸透を待つ。
- 浸透待ち後に水分値を再測定し、終了条件を満たさない場合のみ次の散水を行う。
- PWM評価用のHome Assistant操作もDuty 50%に固定し、15秒・30秒・60秒の時間だけ選択できる。
- 自動散水は安全制御の評価が完了するまで無効のままとする。

## 自動散水アルゴリズム

1. 水分値が設定閾値を下回ると散水サイクルを開始する。
2. 20kHz・Duty 50%で30秒散水する。
3. ポンプを停止して3分間浸透を待つ。
4. 水分値が `設定閾値 + 5%` 以上ならサイクルを終了する。
5. 終了値未満なら、最大3回まで手順2から繰り返す。
6. 2回散水後も開始時より2%以上改善しない場合は `NO_MOISTURE_RESPONSE` でロックする。
7. 3回で終了値へ到達しない場合は `MAX_WATERING_PULSES` でロックする。

ロック後はポンプを再始動しない。水分値が終了値まで回復した場合、または端末を再起動した場合にロックを解除する。ロック中もOTAと水分センサ校正は実行できる。

MQTTのdevice stateには `controllerState`、`wateringPulse`、`wateringLockout`、`wateringFaultCode` を含める。Home Assistantには `Watering Control Status` センサとして表示する。

## 安全確認

1. 吐出口を固定し、漏水しても問題のない場所で実施する。
2. Atom長押しの緊急停止をすぐ操作できる状態にする。
3. 異音、失速、発熱、吐水停止があれば直ちに中止する。
4. 端末によって50% Dutyでも吐水できない場合は、その個体を異常・非適合として扱い、Dutyの手動校正では吸収しない。

## 評価条件

| 操作 | PWM周波数 | Duty | 実行時間 |
|---|---:|---:|---:|
| 固定50%散水・15秒 | 20kHz | 50% | 15秒 |
| 固定50%散水・30秒 | 20kHz | 50% | 30秒 |
| 固定50%散水・60秒 | 20kHz | 50% | 60秒 |

評価では、吐水の有無、散水量、異音、失速、ポンプおよび駆動回路の発熱を確認する。
