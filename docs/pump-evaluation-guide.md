# ポンプ滴下モード実機評価

## 対象ファームウェア

評価用firmware 0.3.13では自動散水を無効化している。ポンプはHome AssistantのPWM評価25〜100%を明示的に実行した場合だけ作動する。

## 安全準備

1. 吐出口を計量容器へ固定する。
2. 漏水しても問題のない場所で実施する。
3. Atom本体ボタンの緊急停止と「ポンプ評価を緊急中止」をすぐ操作できる状態にする。
4. 最初に手動でチューブを満水状態にし、各試験で同じ揚程とチューブ長を使用する。
5. ポンプや駆動回路に異音、停止、発熱があれば直ちに中止する。

## Home Assistantでの操作

次のうち1条件だけを押す。GPIO2には1kHzのハードウェアPWMを10秒間連続出力する。

| 条件 | PWM周波数 | Duty | 実行時間 |
|---|---:|---:|---:|
| PWM 25% | 1kHz | 25% | 10秒 |
| PWM 50% | 1kHz | 50% | 10秒 |
| PWM 75% | 1kHz | 75% | 10秒 |
| PWM 100% | 1kHz | 100% | 10秒 |

「ポンプ評価状態」が完了になるまで次の条件を開始しない。各条件を3回ずつ測定し、`pump-evaluation-results.csv`へ記録する。

## 採用条件

- 10秒間、失速せず安定して吐水する。
- 3回の散水量の変動係数が10%以下である。
- 連続噴射ではなく、目的とする滴下状態になる。
- 異音、失速、過熱がない。
- 条件を満たす中で最小のDutyを採用する。

吐水状態は `滴下`、`細い連続水流`、`通常噴射`、`吐水なし` のいずれかで記録する。チューブが空の条件は別試験とし、通常の流量校正値へ混在させない。
