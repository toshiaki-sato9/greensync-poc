# ポンプ滴下モード実機評価

## 対象ファームウェア

評価用firmware 0.3.18では自動散水を無効化している。31〜36%で吐水しなかった個体について、Home Assistantから40/50/75/100%の基準動作を5秒間だけ確認する。

## 安全準備

1. 吐出口を計量容器へ固定する。
2. 漏水しても問題のない場所で実施する。
3. Atom本体ボタンの緊急停止と「ポンプ評価を緊急中止」をすぐ操作できる状態にする。
4. 最初に手動でチューブを満水状態にし、各試験で同じ揚程とチューブ長を使用する。
5. ポンプや駆動回路に異音、停止、発熱があれば直ちに中止する。

## Home Assistantでの操作

40%から順に1条件だけを押す。GPIO2には20kHzのハードウェアPWMを5秒間出力する。各条件でモーター音・振動・吐水有無を確認し、`COMPLETED`後に次へ進む。吐水した時点で上位Dutyの試験は任意とする。

| 条件 | PWM周波数 | Duty | 実行時間 |
|---|---:|---:|---:|
| 基準動作確認40% | 20kHz | 40% | 5秒 |
| 基準動作確認50% | 20kHz | 50% | 5秒 |
| 基準動作確認75% | 20kHz | 75% | 5秒 |
| 基準動作確認100% | 20kHz | 100% | 5秒 |

100%でもモーター音・振動がなければ、PWM Dutyの個体差評価を終了し、電源、GPIO2、ポンプ駆動回路を確認する。モーター音はあるが吐水しなければ、呼び水、エア噛み、吸水・吐出チューブを確認する。

## 採用条件

- 10秒間、失速せず安定して吐水する。
- 3回の散水量の変動係数が10%以下である。
- 連続噴射ではなく、目的とする滴下状態になる。
- 異音、失速、過熱がない。
- 条件を満たす中で最小のDutyを採用する。

吐水状態は `滴下`、`細い連続水流`、`通常噴射`、`吐水なし` のいずれかで記録する。チューブが空の条件は別試験とし、通常の流量校正値へ混在させない。
